RAG: como dar "memória" e contexto a modelos de IA

RAG (Retrieval-Augmented Generation) é uma técnica que conecta um modelo de linguagem (LLM) a uma base de conhecimento externa. Em vez de depender só do que o modelo "aprendeu" no treinamento, o sistema primeiro busca (retrieval) trechos relevantes de documentos — usando embeddings e um banco de dados vetorial — e injeta esse contexto no prompt antes de gerar (generation) a resposta.

Na prática, isso reduz "alucinações", mantém as respostas atualizadas sem re-treinar o modelo e permite que a IA responda com base nos seus próprios dados (procedimentos, manuais, históricos de processo). É a base de assistentes internos que respondem sobre documentação técnica da empresa. 💡

Dica: combine RAG com dados de processo (ex.: PI System) para criar assistentes que explicam desvios operacionais em linguagem natural.
